# 📋 ウェブ広告エキスパートBronze 問題集アプリ

## 概要

**2026年ウェブ広告エキスパートBronze認定資格試験**の演習問題集アプリです。
公式テキスト（第1章〜第5章）の内容に基づく4択問題を、チャットUI形式で解答できます。

---

## ✅ 実装済み機能

### コア機能
- **5章対応**：第1〜5章の各章10問構成
- **物理ブロック分割出題**：前半3問・中盤4問・後半3問の配分
- **タイプA/B均等出題**：正解を選ぶ問題5問・誤りを選ぶ問題5問（50:50）
- **ランダム出題**：毎回異なる問題順序（ブロック内シャッフル）
- **4択選択式UI**：ボタンクリックまたはキーボード入力（A/B/C/D）

### 進行フロー
1. 起動 → 章選択案内表示
2. 章選択 → OK確認
3. 10問演習（1問ずつ出題）
4. 正誤判定 + 全選択肢解説 + 出典表示
5. 10問終了後 → 採点・評価・問題別結果表示
6. 次の章選択案内へ

### UI機能
- チャット形式の対話型UI
- プログレスバー（進捗・正解数リアルタイム表示）
- 章バッジ表示
- タイピングアニメーション
- レスポンシブデザイン（PC/タブレット/スマートフォン対応）

### 評価システム
| 正答率 | 評価コメント |
|--------|------------|
| 80%以上 | 十分理解できています |
| 60〜79% | 要復習 |
| 59%以下 | テキスト再読推奨 |

## 📊 問題データ仕様

### 問題オブジェクト構造
```javascript
{
  id: "ch1_f01",          // 章_ブロック_番号
  type: "A" | "B",        // A:正解選択 / B:誤り選択
  question: "...",        // 問題文
  choices: { A, B, C, D }, // 4択選択肢
  answer: "B",            // 正解キー
  explanation: {           // 全選択肢の解説
    A: "...", B: "...", C: "...", D: "..."
  },
  source: "第◯章「◯◯」"   // 出典（小タイトルまで明示）
}
```

### ブロック配分
| ブロック | 位置 | 選出数 |
|---------|-----|-------|
| frontPool | 0〜33% | 3問 |
| middlePool | 34〜66% | 4問 |
| backPool | 67〜100% | 3問 |

## 🚧 今後の推奨改善事項

1. **問題数の拡充**：各章・各ブロックに10問以上ストックすることで、毎回異なる問題セットを確実に提供
2. **正答率の永続化**：LocalStorageを使った学習履歴・弱点分析機能の追加
3. **復習モード**：不正解問題のみを再出題するモード
4. **タイマー機能**：本番試験を想定した制限時間設定
5. **PDF内容との照合**：PDFテキストを直接参照した問題の精度向上・追加

## 📝 使用方法

1. アプリを開くと章選択画面が表示されます
2. ボタンまたはテキスト入力（例：「第2章」）で章を選択
3. 「OK」と入力または「OK ▶ 演習開始」ボタンをクリック
4. 問題が1問ずつ表示されるのでA〜Dで回答
5. 解説を確認して次の問題へ進む
6. 10問終了後、採点・評価結果を確認
